# ПокеВайфу Твич Бот - CCG Edition

Electron приложение для управления Твич ботом с системой карточек (CCG).

## Возможности

- 🔐 OAuth2 авторизация через Twitch
- 🎴 Система карточек с рарностями и весами
- 💬 Интеграция с Twitch Chat (TMI.js)
- ⏱️ Система кулдаунов для пользователей
- 🎨 OBS Browser Source оверлей для показа карточек
- 💾 Локальное хранилище карточек с поддержкой картинок
- 🎯 Точное совпадение команд в чате

## Установка

### Требования
- Node.js 14+
- npm или yarn

### Шаги

1. **Клонируй репозиторий и установи зависимости:**
```bash
cd Electron-Bot
npm install
```

2. **Установи дополнительные зависимости для оверлея:**
```bash
npm install express ws
```

## Запуск

### Режим разработки
Запускает React dev server, оверлей-сервер и Electron приложение:
```bash
npm run electron-dev
```

### Только оверлей-сервер
```bash
npm run overlay
```

### Production билд
```bash
npm run electron-build
```

## Конфигурация

### Первый запуск
1. Открой приложение
2. Нажми **АВТОРИЗАЦИЯ** и пройди OAuth2 процесс
3. После авторизации перейди в **НАСТРОЙКИ** и сконфигурируй:
   - Приветственное сообщение при старте
   - Команду для получения карточки (например: `!карта`)
   - Редкости и их веса
   - URL оверлея (автоматически заполнен: http://localhost:3001)

### Добавление карточек
1. Нажми **БАЗА КАРТОЧЕК**
2. Нажми **+ ДОБАВИТЬ КАРТОЧКУ**
3. Заполни:
   - **Имя** карточки
   - **Редкость** (выбери из списка)
   - **Цвет** акцента
   - **Изображение** (загрузится в локальную папку Cards)
4. Нажми **СОХРАНИТЬ**

## OBS Browser Source Setup

### Для OBS Studio

1. В OBS добавь новый источник в сцену:
   - Нажми **Sources** → **+** → **Browser**

2. В окне "Browser Source Properties":
   - **URL:** `http://localhost:3001`
   - **Width:** 400
   - **Height:** 550
   - **Shutdown source when not visible:** (галка опционально)

3. Нажми **OK**

4. **Размещение на сцене:** Перетащи источник на нужное место в сцене

### Использование

Когда кто-то в чате напишет команду (например `!карта`):
1. Бот выберет случайную карточку с учётом редкостей
2. Оверлей автоматически покажет карточку с анимацией
3. Карточка будет видна на протяжении 6 секунд
4. Затем автоматически скроется

## Переменные в формате ответа

В настройке "Формат ответа на команду" можно использовать:
- `{username}` - ник пользователя
- `{cardName}` - имя карточки
- `{rarity}` - редкость карточки
- `{cardColor}` - HEX цвет карточки

Пример: `@{username} получил волшебную {cardName} редкости {rarity}!`

## Команды Twitch Chat

По умолчанию: `!карта`

Пользователь может использовать команду, но:
- Может использовать не чаще чем раз в `cooldownSeconds` секунд
- Если использует раньше - получит сообщение с оставшимся временем

## Troubleshooting

### Оверлей не подключается
- Убедись что оверлей-сервер запущен (`npm run overlay`)
- Проверь firewall - порт 3001 должен быть открыт
- Попробуй перезагрузить браузер источник в OBS

### Картинки не загружаются
- Убедись что картинка добавлена в **БАЗА КАРТОЧЕК**
- Проверь папку: `C:\Users\[Username]\AppData\Local\ccg-bot\Cards\`
- Попробуй переданить с поддерживаемым форматом (PNG, JPG, GIF, WebP)

### Бот не отвечает в чате
- Убедись что OAuth токен валидный (авторизуйся заново)
- Проверь что команда совпадает с тем что в настройках
- Убедись что игра включена в настройках
- Посмотри логи в окне активности
