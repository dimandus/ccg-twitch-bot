# Changelog

## 1.1.0

- Сборка: в пакет входят `public/lib/**`, тестовые карты, распакованный оверлей.
- dimandus: TLS с `rejectUnauthorized: false` только для dimandus.ru; альтернатива — OAuth.
- Чат: авто-реконнект с backoff, фоновый refresh токена, обрезка сообщений до лимита Twitch.
- Оверлей: перезапуск при смене порта в настройках.
- Данные: бэкап/импорт, папка данных, сброс коллекций, переименование редкости на картах.
- UI: онбординг, сгруппированная панель, сортировка и ленивая подгрузка карт, модерация, пресет ответа коллекции.
- Документация: [INSTALL.md](INSTALL.md), обновлённый справочник файлов.
