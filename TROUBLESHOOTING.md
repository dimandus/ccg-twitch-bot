# Помощь и Отладка 🔧

## Логирование и DevTools

### Как открыть DevTools в Electron приложении

Нажми: **Ctrl + Shift + I**

Или в меню: **View** → **Toggle Developer Tools**

Там ты увидишь:
- **Console** - Все ошибки JavaScript и логи
- **Network** - HTTP запросы
- **Sources** - Исходный код

### Типичные проблемы и решения

## 1️⃣ Оверлей не показывается в OBS

### Проблема 1: Чёрный экран в OBS

**Признаки:**
- URL `http://localhost:3001` открывается в браузере
- Но в OBS показывает чёрный экран
- Карточки в чате работают

**Решение:**
1. В OBS нажми правой кнопкой на Browser источник
2. Нажми **Refresh Cache** (Обновить кэш)
3. Если не помогло: удали и добавь источник заново

**Если всё ещё не работает:**
```
1. Закрой OBS полностью
2. Закрой Electron приложение
3. В Terminal: npm run electron-dev
4. Дождись пока оверлей запустится
5. Открой OBS заново
6. Добавь Browser источник с URL: http://localhost:3001
```

### Проблема 2: "Failed to connect" ошибка в браузере

**Признаки:**
- При открытии `http://localhost:3001` видишь ошибку подключения
- В Terminal: ошибка типа "EADDRINUSE" или "Cannot find module express"

**Решение:**
1. Убедись что `npm install` прошёл успешно
2. Проверь что `npm run overlay` запущен (или `npm run electron-dev`)
3. Жди 10 секунд и перезагрузи страницу браузера

**Если порт занят:**
```bash
# Windows: Найди что занимает порт 3001
netstat -ano | findstr :3001

# macOS/Linux:
lsof -i :3001
```

### Проблема 3: Картинка карточки не загружается в оверлее

**Признаки:**
- Оверлей показывает карточку
- Но вместо картинки чёрный квадрат
- Имя и рарность видны

**Решение:**

1. **Проверь что картинка добавлена:**
   - В приложении откой "БАЗА КАРТОЧЕК"
   - Убедись что видишь preview картинки рядом с названием
   - Если preview чёрный → проблема с картинкой, переудобавь

2. **Проверь формат картинки:**
   - Поддерживаемые: PNG, JPG, GIF, WebP
   - Размер не должен быть слишком большой (>5MB)
   - Попробуй переконвертировать в PNG через любой редактор

3. **Проверь путь картинки:**
   - Открой папку: `C:\Users\{username}\AppData\Local\ccg-bot\Cards\`
   - Убедись что там файл вроде `card_1234567.png`
   - Если папка пуста → картинки не сохраняются (ошибка при добавлении)

**Если ничего не помогает:**
```
1. Откой DevTools (Ctrl+Shift+I) в Electron окне
2. Перейди на таб "Console"
3. В приложении добавь карточку с картинкой
4. Посмотри что выведется в Console
5. Скопируй ошибку и посмотри решение ниже
```

## 2️⃣ Бот не отвечает в чате

### Проблема 1: "АВТОРИЗАЦИЯ" не работает

**Признаки:**
- При нажатии на кнопку "АВТОРИЗАЦИЯ" ничего не происходит
- Или открывается браузер но потом зависает

**Решение:**

1. **Проверь интернет:**
   - Откой браузер, зайди на `https://dimandus.ru:5001`
   - Должна быть какая-то ошибка (503, 404 и т.д.), но сервер ответит
   - Если не ответит → проблема с интернетом

2. **Перезагрузи приложение:**
   ```bash
   # Закрой приложение (Alt+F4)
   # В Terminal: Ctrl+C
   # Запусти заново:
   npm run electron-dev
   ```

3. **Проверь что OAuth сервер работает:**
   - Открой DevTools (Ctrl+Shift+I)
   - Перейди на таб "Network"
   - Нажми "АВТОРИЗАЦИЯ"
   - Посмотри запрос к `dimandus.ru`
   - Если статус 400+ → проблема на сервере

### Проблема 2: Бот запущен но не отвечает на команду

**Признаки:**
- Кнопка "ЗАПУСТИТЬ БОТ" зелёная ✅
- Напишешь `!карта` - ничего не происходит
- Нет сообщения от бота в чате

**Решение:**

1. **Проверь что команда совпадает:**
   - В "НАСТРОЙКИ" → "🎴 Игра" → смотри "Команда"
   - По умолчанию: `!карта`
   - Убедись что пишешь ровно то же самое

2. **Проверь что игра включена:**
   - В "НАСТРОЙКИ" → "🎴 Игра" → галка "Включить игру" должна быть поставлена

3. **Проверь что есть хотя бы одна карточка:**
   - В "БАЗА КАРТОЧЕК" должна быть хотя бы одна карточка
   - Если нет → добавь

4. **Смотри логи:**
   - В окне приложения есть таб "Логи"
   - Когда пишешь команду, должна появиться строка
   - Если там ничего нового → сообщение не попало в бота

**Если ничего не помогает:**
```
1. Закрой бот: нажми "ОСТАНОВИТЬ БОТ"
2. Подожди 5 секунд
3. Запусти заново: "ЗАПУСТИТЬ БОТ"
4. Попробуй команду снова
```

### Проблема 3: "Invalid token" ошибка в логах

**Признаки:**
- Бот не отвечает
- В логах: "Invalid OAuth token" или "Invalid refresh token"

**Решение:**

1. **Перепройди авторизацию:**
   - Нажми "ОСТАНОВИТЬ БОТ"
   - Нажми "АВТОРИЗАЦИЯ" заново
   - Подтверди доступ в браузере

2. **Проверь что токен не истёк:**
   - Токены Twitch работают ограниченное время (~60 дней)
   - Если долго не пользовался → перепройди авторизацию

3. **Очистка конфига:**
   ```
   1. Закрой приложение
   2. Открой: C:\Users\{username}\AppData\Local\ccg-bot\config.json
   3. Удали поле "twitch" полностью
   4. Сохрани
   5. Запусти приложение
   6. Пройди авторизацию заново
   ```

## 3️⃣ Проблемы с картинками в "БАЗА КАРТОЧЕК"

### Проблема 1: Картинка дублируется при добавлении

**Признаки:**
- Выбираешь картинку из папки Cards/
- Потом она появляется там ещё раз (дубль)

**Решение:**

Это было в старых версиях. Если всё ещё происходит:
1. Открой `public/main.js`
2. Найди функцию `moveImageFile`
3. Проверь что там логика проверки `if (src.includes('Cards/'))`

На текущей версии это должно быть исправлено.

### Проблема 2: Ошибка при добавлении картинки

**Признаки:**
- Нажимаешь "Добавить картинку"
- Выбираешь файл
- Появляется ошибка "Failed to save image"

**Решение:**

1. **Проверь что папка Cards создана:**
   ```
   C:\Users\{username}\AppData\Local\ccg-bot\Cards\
   ```
   Если папки нет → создай вручную

2. **Проверь права доступа:**
   - Нажми правой кнопкой на папку `ccg-bot`
   - Свойства → Безопасность
   - Убедись что твой пользователь может писать в папку

3. **Проверь размер файла:**
   - Картинка не должна быть > 10MB
   - Попробуй меньший файл

### Проблема 3: Preview картинки не загружается в "БАЗА КАРТОЧЕК"

**Признаки:**
- Добавил карточку
- В списке видишь название
- Но вместо изображения чёрный квадрат

**Решение:**

Это обычно означает что картинка в неправильном формате или повреждена:

1. Переудобавь картинку
2. Убедись что формат: PNG, JPG, GIF или WebP
3. Попробуй открыть картинку в Windows Photo или другом просмотрщике
   - Если там тоже чёрный экран → файл повреждён

## 5️⃣ Чтение логов консоли

### Как понять ошибку из DevTools Console

**Типичные ошибки:**

```
TypeError: Cannot read property 'x' of undefined
```
Смысл: Пытаешься получить свойство из чего-то пустого
Решение: Проверь что данные загружены перед использованием

```
CORS error: Access-Control-Allow-Origin
```
Смысл: Нет доступа к внешнему ресурсу
Решение: Проверь URL, может быть неправильный домен

```
Module not found: 'express'
```
Смысл: express не установлен
Решение: `npm install express`

Перед началом стрима убедись что:

- [ ] `npm run electron-dev` запущен
- [ ] Приложение авторизовано (зелёный статус)
- [ ] Кнопка "ЗАПУСТИТЬ БОТ" активна и можно нажать
- [ ] В "БАЗА КАРТОЧЕК" есть хотя бы 5 карточек
- [ ] В OBS добавлен Browser источник с URL `http://localhost:3001`
- [ ] OBS источник виден на сцене (не чёрный экран)
- [ ] Ты проверил команду локально написав `!карта` от своего аккаунта

Если всё галочками → готов к стриму! 🎉
