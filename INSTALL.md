# Установка CCG Twitch Bot

Версия приложения: **1.1.0**

## Сборка для Windows

```bash
npm install
npm run electron-build
```

Готовый установщик появится в папке `dist/`. На чистой машине **без Node.js** установите `.exe` из `dist/` и запустите ярлык.

## Первый запуск

1. **Авторизация** — кнопка «Авторизация» (основной путь через dimandus.ru) или окно **OAuth** (прямой Twitch PKCE, если не доверяете сертификату dimandus).
2. **Карты** — «База карточек» или тестовый набор: `npm run seed:cards` (только при разработке).
3. **OBS** — в «Настройки» скопируйте URL Browser Source (`http://127.0.0.1:порт`). При смене порта сохраните настройки — оверлей перезапустится сам.
4. **Старт** — «Старт бота», включите игру в настройках при необходимости, проверьте `!карта` и `!коллекция` в чате.

## Прямой Twitch OAuth (резерв)

1. Откройте **OAuth** в приложении.
2. Укажите **Client ID** (и **Client Secret**, если используете confidential app).
3. В [Twitch Developer Console](https://dev.twitch.tv/console/apps) добавьте redirect: `http://localhost:43781`
4. Scopes: `chat:read`, `chat:edit`, `channel:bot` и связанные из подсказки в окне.
5. Сохраните и нажмите авторизацию в режиме **direct**.

## Где лежат данные

`%AppData%\ccg-twitch-bot\ccg-bot\` — config, cards, collections, cooldowns, папка `Cards/`.  
В настройках: **Открыть папку данных** и **Экспорт/импорт бэкапа** (токены в бэкап не попадают).
