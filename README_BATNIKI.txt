📋 ИНСТРУКЦИЯ:

1️⃣  ПЕРВЫЙ ЗАПУСК
   ▶️ Двойной клик на: START.bat
   
   Этот батник:
   - Проверит наличие зависимостей (node_modules)
   - Если их нет - установит их автоматически (это займет 1-2 минуты)
   - Запустит приложение
   
   ⏱️ Время: 1-3 минуты при первом запуске

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣  БЫСТРЫЙ ЗАПУСК (после первого запуска)
   ▶️ Двойной клик на: START_QUICK.bat
   
   Этот батник:
   - Сразу запускает приложение (без проверок)
   - Быстрее, чем START.bat
   
   ⏱️ Время: 5-10 секунд
   
   ⚠️ Используйте только если START.bat успешно выполнен

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3️⃣  СБОРКА ПРИЛОЖЕНИЯ (для распространения)
   ▶️ Двойной клик на: BUILD.bat
   
   Этот батник:
   - Собирает финальное приложение
   - Создает установщик и портативную версию
   - Результат будет в папке dist/
   
   ⏱️ Время: 2-5 минут
   
   📦 Результат: готовый .exe файл для других компьютеров

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔧 ТРЕБОВАНИЯ:

   Скачать: https://nodejs.org/

✅ Интернет соединение (для установки зависимостей при первом запуске)

❓ ЧАСТЫЕ ОШИБКИ:

❌ "Node is not recognized"
   ➜ Node.js не установлен или не добавлен в PATH
   ➜ Установите Node.js с https://nodejs.org/

❌ "npm is not recognized"
   ➜ Перезагрузитесь после установки Node.js
   ➜ Или откройте батник заново

❌ Порт 3000 уже занят
   ➜ Закройте другое приложение, использующее порт 3000
   ➜ Или отредактируйте START.bat и добавьте: set PORT=3001

💡 СОВЕТЫ:

- Для остановки приложения закройте Electron окно
