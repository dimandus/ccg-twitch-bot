# Инструкции по запуску

## Шаг 1: Установка зависимостей

Откройте терминал в папке `Electron-Bot` и выполните:

```bash
npm install
```

Это установит все необходимые зависимости (React, Electron, etc.)

## Шаг 2: Запуск в режиме разработки

```bash
npm run electron-dev
```

Это запустит два процесса одновременно:
- React приложение на http://localhost:3000
- Electron окно с приложением

**Внимание:** При первом запуске может занять 1-2 минуты.

## Шаг 3: Тестирование функционала

Когда приложение откроется, вы сможете тестировать:

1. **Главная страница** - Отображает логи и кнопки управления
2. **Кнопка "СТАРТ БОТА"** - Запускает бота (кнопка становится неактивной, добавляет лог)
3. **Кнопка "СТОП БОТА"** - Останавливает бота
4. **Кнопка "АВТОРИЗАЦИЯ"** - Авторизует бота в Twitch
5. **Боковое меню** - Навигация между разделами (Главная, Логи, Настройки, База карточек)

## Сборка для продакшена

```bash
npm run electron-build
```

Это создаст распределяемое приложение в папке `dist`.

## Пробелемы и решения

### Проблема: "Cannot find module 'electron'"
**Решение:** Убедитесь, что вы выполнили `npm install` и находитесь в папке `Electron-Bot`

### Проблема: Порт 3000 уже занят
**Решение:** Запустите на другом порту: `PORT=3001 npm run electron-dev`

### Проблема: Приложение не запускается после `npm install`
**Решение:** Удалите `node_modules` и `package-lock.json`, затем снова выполните `npm install`

## Hot Reload

При разработке изменения в React коде будут автоматически отражены (Hot Reload).
Для изменений в Electron main процессе потребуется перезагрузка окна.
