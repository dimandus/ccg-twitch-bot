# Быстрый старт OBS Overlay 🎨

## За 5 минут до первого показа карточки!

### Шаг 1: Установка зависимостей (1 минута)

Открой Terminal в папке `Electron-Bot`:

```bash
npm install
```

Это установит все нужные пакеты включая `express` и `ws` для оверлея.

### Шаг 2: Запуск приложения (1 минута)

```bash
npm run electron-dev
```

Это запустит:
- ✅ Оверлей-сервер на `http://localhost:3001`
- ✅ React приложение на `http://localhost:3000`
- ✅ Electron окно с интерфейсом

### Шаг 3: Настройка в приложении (2 минуты)

1. **Авторизуйся через Twitch**
   - Нажми кнопку "АВТОРИЗАЦИЯ"
   - Подтверди доступ
   - Вернись в приложение

2. **Включи оверлей в НАСТРОЙКАХ**
   - Нажми "НАСТРОЙКИ"
   - Прокрути вниз до "🎨 Настройки оверлея"
   - Поставь галку "Включить оверлей"
   - URL уже заполнен: `http://localhost:3001`
   - Нажми кнопку "📋 Копировать" чтобы скопировать URL

3. **Настрой команду получения карточки**
   - В той же окне НАСТРОЙКИ найди "🎴 Игра"
   - Включи "Игра"
   - Проверь что команда: `!карта` (или своя)
   - Проверь кулдаун: 60 секунд (можно менять)

### Шаг 4: Добавь одну карточку (1 минута)

1. Нажми "БАЗА КАРТОЧЕК"
2. Нажми "+ ДОБАВИТЬ КАРТОЧКУ"
3. Заполни:
   - **Имя:** Тестовая
   - **Редкость:** Common
   - **Цвет:** Выбери любой
   - **Изображение:** Выбери или загрузи тестовую картинку
4. Нажми "СОХРАНИТЬ"

### Шаг 5: Добавь оверлей в OBS

#### Для OBS Studio:

1. **Новый источник:**
   - В OBS откой сцену
   - **Sources** → **+** (добавить источник)
   - Выбери **Browser** (Браузер)

2. **Настройки:**
   - **Name:** "CCG Card Overlay" (или любое имя)
   - **URL:** `http://localhost:3001`
   - **Width:** 400
   - **Height:** 550
   - **FPS:** 30 (по умолчанию)
   - **Shutdown source when not visible:** Галка опционально

3. **Сохрани** и закрой окно

4. **Размещение:** 
   - Перетащи источник на нужное место в сцене
   - Измени размер если нужно (Ctrl+Drag за углы)

#### Проверка работы:

```bash
npm run test-overlay
```

Это отправит тестовую карточку на оверлей. Должна появиться в браузере!

### Шаг 6: Тест с реальной командой

1. **Запусти бот:**
   - Нажми "ЗАПУСТИТЬ БОТ" в приложении
   - Должен зелёный индикатор "🟢 Бот работает"

2. **Напиши в своём чате на Twitch:**
   ```
   !карта
   ```

3. **Что должно произойти:**
   - ✅ Бот ответит сообщение типа: `@username 🎴 Тестовая (Common)`
   - ✅ Карточка появится на оверлее с анимацией
   - ✅ После 6 секунд карточка исчезнет
   - ✅ В лог приложения добавится запись

### Troubleshooting

#### "Оверлей не показывается"

**Проблема:** Карточка в чате работает, но в OBS её нет

**Решение:**
1. В OBS нажми правой кнопкой на Browser источник
2. Нажми **Refresh Cache** (Обновить кэш)
3. Попробуй отправить карточку снова (`!карта` в чате)

Если не сработало:
- Проверь URL в OBS Browser: должно быть ровно `http://localhost:3001`
- Убедись что `npm run overlay` работает (должен быть запущен)
- Открой `http://localhost:3001` в браузере - должна показать чёрный экран (ждёт карточку)

#### "Порт 3001 занят"

**Проблема:** Ошибка "EADDRINUSE: address already in use :::3001"

**Решение:**
1. Закрой ВСЕ окна приложения
2. Дождись 10 секунд
3. Запусти заново: `npm run electron-dev`

Если не помогает:
```bash
# Windows PowerShell
Get-Process -Id (Get-NetTCPConnection -LocalPort 3001).OwningProcess | Stop-Process -Force

# macOS/Linux
lsof -ti:3001 | xargs kill -9
```

#### "Картинка карточки чёрная / не загружается"

**Проблема:** Оверлей работает, но картинка не видна

**Решение:**
1. Убедись что добавил карточку в "БАЗА КАРТОЧЕК"
2. При добавлении проверь что картинка загрузилась (должна быть preview)
3. Попробуй добавить карточку с другой картинкой (png, jpg)

#### "АВТОРИЗАЦИЯ не работает"

**Проблема:** При нажатии "АВТОРИЗАЦИЯ" ничего не происходит

**Решение:**
1. Проверь что интернет работает
2. Убедись что `dimandus.ru:5001` доступен
3. Попробуй перезагрузить приложение

После успешного теста:

   - Пример: "@{username} 💫 {cardName} ({rarity}) блеснула разноцветным светом!"

4. **Включи приветствие при старте**
   - "НАСТРОЙКИ" → "💬 Приветствие"
   - Включи и напиши сообщение типа: "Привет всем! Бот готов выдавать карточки! Пиши !карта"

## Команды для разработчика

```bash
npm run start           # Только React dev server
npm run overlay         # Только оверлей-сервер
npm run electron-dev    # Все вместе (рекомендуется)
npm run build          # Build React
npm run electron-build # Full production build
npm run test-overlay   # Отправить тестовую карточку
npm run eject          # Распаковать react-scripts (осторожно!)
```

## Файлы конфигурации

- **Настройки сохраняются:** `C:\Users\{user}\AppData\Local\ccg-bot\config.json`
- **Карточки сохраняются:** `C:\Users\{user}\AppData\Local\ccg-bot\cards.json`
- **Картинки сохраняются:** `C:\Users\{user}\AppData\Local\ccg-bot\Cards\`

Всё автоматически! 

## Помощь

Если что-то не работает:

1. Проверь что все процессы запущены: `npm run electron-dev`
2. Открой DevTools в Electron окне: **Ctrl+Shift+I**
3. Проверь Console на ошибки (красные сообщения)
4. Посмотри на логи в приложении (таб "Логи")
5. Проверь что `http://localhost:3001` открывается в браузере

Удачи! 🚀
